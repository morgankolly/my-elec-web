Client-Side Pages

  • index.php - Homepage
  • about.php - About page
  • services.php - Services page
  • portfolio.php - Portfolio showcase
  • blog.php - Blog listing
  • post.php - Single blog post
  • contact.php - Contact form

Admin Panel Structure

  • admin/index.php - Authentication page
  • admin/dashboard.php - Admin homepage
  • admin/posts.php - Manage blog posts
  • admin/services.php - Manage services
  • admin/portfolio.php - Manage portfolio
  • admin/use-cases.php - Manage use cases
  • admin/newsletter.php - Manage newsletter
  • admin/seo.php - Manage SEO metadata
  • admin/users.php - Manage users

Directory Structure

  • assets/ - Global client-side assets (CSS, JS, images)
  • admin/assets/ - Admin-specific assets
  • admin/controllers/ - PHP controllers
  • admin/config/ - DB connection, environment configs
  • admin/model/ - Data models
  • admin/components/ - Reusable admin UI parts
  • admin/helpers/ - Utility functions
  • components/ - Client-side reusable components
  • vendors/ - External libraries
